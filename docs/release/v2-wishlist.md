# TPCRM Version 2 Wishlist

Ideas for post-v1.0. **Not committed.** Architecture may change.

## CRM Enhancements

- Lead scoring and prioritization
- Email integration (inbound/outbound tracking)
- Calendar sync (Google/Outlook) for demos and follow-ups
- Bulk import/export (CSV)
- Advanced duplicate merge (not just detection)
- Lead assignment rules and round-robin
- Custom fields on leads

## Communication

- Email templates
- SMS templates
- Notification center (in-app)
- @mentions and internal notes threading

## Reporting & Analytics

- Custom report builder
- Funnel analytics
- Conversion rate by source/stage
- Scheduled report emails
- Export to PDF/Excel

## Administration

- Branding / theme customization
- Feature flags
- API keys and webhooks
- Backup management UI
- Multi-organization support
- Audit log viewer UI

## Platform

- Mobile-responsive PWA or native app
- Real-time updates (Supabase Realtime)
- Full-text search (PostgreSQL FTS or external)
- Workflow automation (triggers/actions)
- Integration marketplace (Zapier, Slack)

## Quality & Ops

- Full E2E test suite in CI
- Performance budgets in CI
- Staging preview environments per PR
- Error tracking (Sentry)
- Analytics (privacy-conscious usage metrics)

## UX

- Breadcrumb navigation
- Global search (leads, contacts, activities)
- Keyboard shortcuts
- Dark mode toggle (design tokens ready)
- Dashboard customization per role
